Monthly Sales Trend – Veda Technology

📌 Task Overview

This project is part of my Veda Technology Data Analytics Internship.

The task is to analyze the Sample Superstore dataset and summarize sales by month.

🎯 Objective

* Calculate total sales for each month.
* Arrange the months in chronological order.
* Create a line chart to visualize the monthly sales trend.

🛠️ Tools Used

* Microsoft Excel
* Sample Superstore Dataset

📊 Work Done

* Used Order Date to group sales by month.
* Used Sales to calculate monthly total sales.
* Created a monthly sales table from January to December.
* Created a Line Chart named Monthly Sales Trend.

📁 Deliverables

* Monthly Sales Table
* Monthly Sales Trend Line Chart

📌 Conclusion

The monthly sales analysis helps to understand how sales change throughout the year and identify months with higher or lower sales.
